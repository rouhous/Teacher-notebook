# جدولي – إدارة الدروس الخصوصية

تطبيق ويب تقدمي (PWA) لإدارة الطلاب والحصص والاشتراكات والمدفوعات.

## الخصوصية وحفظ البيانات
- لا يتطلب التطبيق إنشاء حساب.
- تُحفظ بيانات كل مستخدم في مساحة التخزين المحلية للمتصفح على جهازه (`localStorage`).
- لا تُرسل سجلات الطلاب أو المدفوعات إلى مستودع GitHub أو إلى خادم التطبيق.
- ملفات التطبيق العامة لا تحتوي على أسماء طلاب أو سجلات شخصية مُسبقة.
- عند حذف بيانات المتصفح أو تغيير الجهاز قد تُفقد البيانات؛ استخدم زر **نسخة احتياطية** بانتظام، واحفظ ملف JSON في مكان آمن.
- استعادة نسخة احتياطية تستبدل السجلات الحالية بعد تأكيد المستخدم.

## النشر
انشر محتويات هذا المجلد عبر HTTPS. تأكد من أن `index.html` و`manifest.webmanifest` و`sw.js` ومجلد `icons` في المسار نفسه.

## التشغيل دون اتصال
بعد فتح التطبيق مرة واحدة مع اتصال بالإنترنت وإتمام تحميل ملفات التطبيق، تسجل خدمة `sw.js` ملفات الواجهة للتشغيل دون اتصال. قد تتطلب بعض وظائف المتصفح أو مشاركة الملفات اتصالاً أو دعماً من الجهاز.

## تنبيه
التخزين المحلي مرتبط بالمتصفح/الجهاز وملف المستخدم؛ لا يُعد بديلاً عن النسخ الاحتياطي. لا تمسح بيانات الموقع قبل تصدير نسخة احتياطية.
