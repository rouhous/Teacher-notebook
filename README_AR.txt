دفتر المعلم الرقمي — إصدار PWA

1. احفظ نسخة احتياطية JSON من التطبيق الحالي قبل الاستبدال.
2. ارفع جميع الملفات الموجودة في هذا ZIP إلى جذر مستودع GitHub Pages الخاص بك Teacher-notebook (ليس ZIP نفسه).
3. احتفظ بالأسماء index.html و sw.js و manifest.webmanifest وملفات الأيقونات.
4. افتح https://rouhous.github.io/Teacher-notebook/ في Chrome أو Brave.
5. من قائمة المتصفح اختر Install app / إضافة إلى الشاشة الرئيسية.
6. افتح التطبيق مرة واحدة مع اتصال بالإنترنت لتخزين الملفات الأساسية، ثم جرّب وضع الطيران.
7. للمزامنة مع Google Drive يجب توفر الإنترنت.

ملاحظات:
- التخزين المحلي مرتبط بالموقع/المتصفح: بيانات ملف HTML المفتوح من الهاتف لن تنتقل تلقائيا إلى نسخة GitHub Pages. استخدم تصدير/استيراد JSON أو الاستعادة من Google Drive.
- PDF.js والخطوط الخارجية تعتمد على CDN؛ بعض وظائف استيراد PDF قد لا تعمل دون إنترنت. بقية واجهة الدفتر وبياناته المحلية مصممة لتعمل دون اتصال بعد التخزين المؤقت.
- المزامنة السحابية ليست تلقائية بالكامل؛ استخدم أزرار المزامنة/الاستعادة ولا تجرّب استعادة بيانات فوق سجلات مهمة دون نسخة احتياطية.
- في تحديثات PWA: عند الاتصال بالإنترنت أعد فتح الصفحة لتحديث النسخة المخزنة؛ أغلق التطبيق وافتحه بعد تحديثه.
